# Bharat Unforgettable

A responsive travel discovery and booking front end for India. The current release is a self-contained static prototype in `index.html`.

## What’s included

- Responsive landing page for desktop and mobile
- Destination cards for Jaipur, Ladakh, Kerala, and Goa
- Search tabs for stays, experiences, and flights
- Search form feedback, destination prefill, mobile navigation, and newsletter feedback
- Accessible labels, keyboard-friendly controls, and reduced-motion support

## Preview

Open `index.html` directly in a browser, or serve this repository with any static file server.

## Booking and accounts

This prototype does not connect to live inventory, payments, email signup, or user accounts. Search and sign-in controls explain that those services still need to be connected. Before accepting bookings, add a backend/API for availability and pricing, secure account authentication, payment processing, booking confirmation, and cancellation/refund handling.

## Images and fonts

The page loads photography from Unsplash and fonts from Google Fonts. A network connection is needed for those external assets. Replace these URLs with licensed, locally managed assets before production if your deployment requires self-hosted media.
